# AI PARASAT — микрофонмен сөйлесетін қазақша AI-аватар

Адам микрофонға сұрақ айтады → браузер қазақ тіліндегі сөзді таниды → **Claude** жауап ойлайды →
**«Айгүл»** нейрондық дауысы оны қазақша оқиды → экрандағы қыз ернін дыбысқа қарай қимылдатып,
қолымен түсіндіріп тұрғандай жест жасайды.

```
микрофон → сөзді тану (Chrome kk-KZ / Whisper) → server.py → Claude (ми)
                                                       ↓
экран ← ерін + қол + дене қимылы ← «Айгүл» дауысы (edge-tts, MP3)
```

---

## 🔑 API КІЛТІ ҚАЙДА ТҰРАДЫ

Кілт **тек бір жерде** тұрады: жоба папкасындағы **`.env`** файлында.

```
parasat_avatar/
└── .env      ← ОСЫ ФАЙЛ
```

Файлды ашып, 7-жолды табыңыз:

```
ANTHROPIC_API_KEY=
```

Теңдік белгісінен кейін кілтіңізді бос орынсыз, тырнақшасыз қойыңыз:

```
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxx
```

Сақтаңыз (Ctrl+S / Cmd+S) және серверді қайта іске қосыңыз.

**Кілтті қайдан алу:**
1. https://console.anthropic.com сайтына кіріңіз (тіркеліңіз).
2. **Billing** → карта қосып, балансты толтырыңыз (5 $ ашылуға жетеді).
3. **API Keys** → **Create Key** → `sk-ant-...` кілтін көшіріңіз (ол тек бір рет көрсетіледі).

> ⚠️ `.env` файлы кейде жасырын болады (атауы нүктеден басталады).
> VS Code және PyCharm оны көрсетеді. macOS Finder-де көру: **Cmd + Shift + .**
> Кілтті ешкімге жібермеңіз, чатқа немесе GitHub-қа салмаңыз.

## ✅ Не керек
- **Python 3.10–3.13** (python.org)
- **Google Chrome** немесе **Microsoft Edge** (микрофон үшін)
- **Интернет** (Claude, дауыс және сөзді тану интернет арқылы жұмыс істейді)
- Сыртқы микрофон (ұсынылады — ноутбуктың микрофоны залдың шуын көп ұстайды)

## ▶️ VS Code-та іске қосу
1. **File → Open Folder** → `parasat_avatar` папкасын ашыңыз.
2. Ұсынылған **Python** кеңейтімін орнатыңыз (оң жақ төменде шығады).
3. **Terminal → New Terminal** ашып, орындаңыз:
   ```
   python -m venv venv
   ```
   - Windows: `venv\Scripts\activate`
   - macOS: `source venv/bin/activate`
   ```
   pip install -r requirements.txt
   ```
4. `.env` файлына кілтті қойыңыз (жоғарыдағы бөлім).
5. Тексеріңіз: `python check.py` — бәрі **[OK]** болуы керек.
6. Іске қосыңыз: сол жақтағы **Run and Debug** (▶) → **«PARASAT: серверді іске қосу»** → F5.
   Немесе терминалда: `python server.py`
7. Chrome-да ашылады: **http://127.0.0.1:8000**

## ▶️ PyCharm-да іске қосу
1. **File → Open** → `parasat_avatar` папкасы.
2. PyCharm виртуал орта (venv) жасауды ұсынады → **OK**.
   Ұсынбаса: *Settings → Project → Python Interpreter → Add Interpreter → Virtualenv*.
3. Төмендегі **Terminal**-да: `pip install -r requirements.txt`
4. `.env` файлына кілтті қойыңыз.
5. `check.py` → оң жақ батырма → **Run 'check'** — бәрі **[OK]** болуы керек.
6. `server.py` → оң жақ батырма → **Run 'server'**.
7. Chrome-да: **http://127.0.0.1:8000**

## ▶️ Бір басумен
- **Windows:** `start.bat` файлын екі рет басыңыз.
- **macOS:** `start.command` файлын екі рет басыңыз (алғашқы рет: оң жақ батырма → **Open**).
  Терминалдан: `bash start.sh`

## 🎤 Қалай қолданылады
1. Бетте **«ЖҮЙЕНІ ІСКЕ ҚОСУ»** батырмасын басыңыз → жүктелу → SYSTEM ONLINE →
   қыз ұшқындардан жиналып, «Сәлеметсіздер ме! Парасат апталығына қош келдіңіздер!…» дейді.
2. Браузер микрофонға рұқсат сұрайды → **Рұқсат беру (Allow)**.
3. Экрандағы үлкен **микрофон** батырмасын басыңыз (немесе **Space**) → сұрақты қазақша айтыңыз.
   Сөйлеп болған соң ол өзі тоқтап, жауап береді.

| Әрекет | Қалай |
|---|---|
| Сұрақ қою | экрандағы микрофон немесе **Space** |
| Сөзін тоқтату | **Esc** немесе сөйлеп тұрғанда микрофонды басу |
| Жасырын оператор панелі | **Shift + S** (дайын сұрақтар, жазу жолы, «Басынан бастау», «Жаңа келуші», Whisper таңдау) |
| Толық экран | **B** немесе панельдегі «Үлкен экран» |

## 🗣 Дауысты және «миды» баптау (`.env`)
| Жол | Мағынасы |
|---|---|
| `TTS_VOICE=kk-KZ-AigulNeural` | әйел дауысы; ер дауысы: `kk-KZ-DauletNeural` |
| `TTS_RATE=-5%` | баяуырақ сөйлейді (`+5%` — жылдамырақ) |
| `TTS_PITCH=+5Hz` | дауысы жіңішкерек |
| `CLAUDE_MODEL=claude-sonnet-5-5` | қазақшасы ең жақсы; `claude-haiku-5-5` — жылдамырақ, арзанырақ |

**Не білетінін өзгерту:**
- `persona.md` — қыздың мінезі, қалай сөйлейтіні, нені істемейтіні.
- `knowledge.md` — **білім базасы**: апталық кестесін, жоба авторларының аты-жөнін, көрме орнын жазыңыз.
  Ол осы деректерге сүйеніп жауап береді.

Өзгерткен соң серверді қайта іске қосыңыз.

## 👂 Қазақша сөзді жақсырақ тану (Whisper, міндетті емес)
Chrome қазақша сөзді нашар таныса:
1. `requirements.txt` ішіндегі `# faster-whisper>=1.0` жолынан `#` белгісін алыңыз.
2. `pip install -r requirements.txt`
3. `.env` ішінде `WHISPER_MODEL=medium` (дәлірек) немесе `small` (жылдамырақ).
4. Серверді қайта іске қосып, **Shift + S** → «Тану: Whisper (сервер)» таңдаңыз.
   Алғашқы рет модель жүктеледі (~1,5 ГБ).

| Дауыс жоқ | `python check.py` → 4-қадам; интернет пен компьютердің дыбысын тексеріңіз |

| `pip` табылмайды | `python -m pip install -r requirements.txt` |
